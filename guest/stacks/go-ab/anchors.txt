# deterministic-vmm Phase-2b Go A/B stack — runtime anchors (spec item 7).
#
# These pin what the "chatty runtime" measurement is measuring. The Go toolchain
# version + base digests + the built layer's content-identity are captured
# MACHINE-SIDE into stack.lock on every bake (bake-stack.sh); this file documents
# the runtime-configuration anchors and why they are left at their defaults.
#
# Measured at DEFAULTS on purpose (the spec forbids tuning GOGC/GOMAXPROCS — the
# point is to see how a stock Go runtime behaves under fast-forward):
#
#   Go toolchain      go1.26.5 (pinned golang image
#                     golang@sha256:0178a641fbb4858c5f1b48e34bdaabe0350a330a1b1149aabd498d0699ff5fb2;
#                     GOTOOLCHAIN=local so nothing is downloaded at build time).
#                     The exact `go version` string is recorded in stack.lock by
#                     bake-stack.sh (toolchain= line).
#
#   GOGC              default = 100 (NOT set). Forced GC runs ~every 2 min of
#                     (virtual) idle time via the runtime's forcegc; this is the
#                     ~2-min spike signature in the Δvtsc histogram.
#
#   GOMAXPROCS        default = the single guest vCPU = 1 (NOT set). Single-core
#                     already quiets the runtime relative to multi-core (fewer
#                     Ps, less sysmon/scheduler churn), so the measured chattiness
#                     is a FLOOR, not a ceiling — a multi-core guest would be
#                     strictly chattier.
#
#   Runtime base      alpine@sha256:14358309a308569c32bdc37e2e0e9694be33a9d99e68afb0f5ff33cc1f695dce
#                     + postgresql16-client=16.14-r0 (same client the shell
#                     service uses; the Go service shells out to it, so the SQL is
#                     byte-identical and the ONLY variable is the Go runtime).
#
# Compose CLI (owed from 2a) is recorded in guest/manifest.txt alongside vmlinux
# + initramfs + CPUID: version + sha256 of the pinned static binary (source of
# truth: guest/initramfs-alpine/compose-engine.lock).
